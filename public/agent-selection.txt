# Use Armorial while building a UI

Choose existing, consistent interface icons in English or Simplified Chinese.
Armorial supplies the IconPark collection, executable project appearance,
compact selection and deterministic SVG. The human or Agent chooses metaphors
and evaluates how the result works in the interface.

## Task fit

Useful for a new page, toolbar, navigation or control set when IconPark fits.
Preserve an existing project icon system when it already serves the design.
Armorial does not draw logos, illustrations or arbitrary SVG geometry.

For example, a request to build a settings page can lead to selecting search,
settings and close icons without asking the user to name an icon tool.
Ambiguity from the matcher is a set of candidates for judgment, not an automatic
requirement to ask the user.

## Agent entry points

- `select_icons({intents:["search","settings","close"]})`: up to 20 meanings,
  no SVG rendering, ordered results, policy, and unresolved candidates.
- `resolve_icon({intent:"search"})`: one meaning and its rendered SVG.
- `search_icons({query:"notification"})`: compare candidates.
- `get_icon` / `get_icons`: render chosen ids; up to 8 SVGs per MCP batch.
- `choose_icon`: open the visual workbench for a human choice.

The CLI offers `select`, `resolve`, `search`, `get`, and `batch`. Use the available
installed command, Host launcher, or a deliberately built source installation.
Older versions may lack `select`; their resolve/search routes remain usable.
Agent Host is optional, and ordinary CLI/MCP operations work offline after build.

## Human entry point

Open https://tetracoralla.github.io/armorial/ to search, compare and adjust
appearance. Copy SVG, download or drag the asset. Copy link reopens the exact id
and style, with a hash check; a mismatch is shown for review. The URL fragment
contains no project path or policy name. Copy for Agent carries a typed choice
back to a task. Figma has a separate offline development plugin.

## Installation and version

Source, GitHub releases and the hosted workbench are public. npm and official
MCP Registry publication are not claimed. Do not assume `npx armorial` is a
published installation. Node.js 22 or newer is required for the source runtime.
The hosted `source-commit.txt` identifies its deployed source; local unreleased
features may be newer.

To inspect the exact deployed source:

```sh
ARMORIAL_COMMIT=$(curl -fsSL https://tetracoralla.github.io/armorial/source-commit.txt)
printf '%s\n' "$ARMORIAL_COMMIT" | grep -Eq '^[0-9a-f]{40}$'
git clone https://github.com/tetracoralla/armorial.git
cd armorial
git checkout --detach "$ARMORIAL_COMMIT"
npm ci --ignore-scripts
npm run build:node
node dist/adapters/cli.js resolve settings --format text
```

## Output and effects

Selection/search/MCP calls do not write files. Explicit CLI batch output creates
a sprite or a distinct HTML candidate and preserves existing files by default.
Interrupted writes require destination inspection before retry. See the artifact
guide for explicit replacement modes and recovery. Appearance overrides report
the effective policy and whether it was changed. Local queries are not sent to
an Armorial service. Human clipboard, download, Figma insertion and connected
selection delivery are explicit actions.
