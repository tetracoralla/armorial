Open the visual workbench

Choose icons while building a UI

Find existing IconPark icons, compare their meaning and appearance, and deliver consistent SVG to a page, app, or Figma design. People and Agents use the same local kernel.

Start with the interface

Armorial fits new navigation, toolbars and controls that need a coherent icon set. Keep an existing project library when it already serves the design. The caller chooses the metaphor and judges the result; a deterministic ambiguity supplies candidates for that judgment.

Select before rendering

select_icons({ intents: ["search", "settings", "close"] })

Up to 20 meanings return ordered ids, project style and unresolved candidates without generating SVG. Keep successful choices and refine the rest. Use resolve_icon for one meaning with SVG, search_icons to explore, and get_icon or get_icons to render chosen ids.

Compare and share visually

In the workbench, search, select and adjust appearance, then copy SVG, download or drag. Copy link reopens the exact id and style, with a hash check. A changed asset is flagged for review. Copy for Agent returns the selection to a task. choose_icon opens this visual comparison in a compatible MCP host.

Install without a host dependency

Node.js 22 or newer runs the source CLI and MCP server. An installed CLI or Host launcher also works. Agent Host is optional. Public npm and official MCP Registry installation are not claimed.

git clone https://github.com/tetracoralla/armorial.git
cd armorial
npm ci
npm run build
node dist/adapters/cli.js select search settings close

Deployed source commit identifies this workbench's version. The plain-text guide includes a deployment-pinned source probe. Unreleased local features may be newer.

Output and effects

Armorial supplies existing IconPark geometry, not logos, illustrations or arbitrary SVG edits. Local queries are not sent to an Armorial service. MCP calls do not write files; explicit CLI file output preserves existing files by default. Clipboard, download, Figma insertion and connected human selection are explicit actions.
